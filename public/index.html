Hướng dẫn sử dụng FakeIDM

Trình tăng tốc tải xuống đa luồng cá nhân
1. Thêm lượt tải:

Bấm nút Thêm URL trên thanh công cụ hoặc nhấn phím tắt ⌘N. Bạn có thể dán link trực tiếp hoặc thả link vào cửa sổ ứng dụng.

2. Tiếp tục tải khi bị gián đoạn:

Chọn dòng file cần tiếp tục rồi bấm nút Tiếp tục. FakeIDM tự động xác thực phiên bản file qua ETag/Last-Modified để tránh ghép sai dữ liệu.

3. Theo dõi phân đoạn đa luồng:

Nhấp đúp chuột vào bất kỳ file nào để xem bảng phân đoạn mạng 8–16 kết nối song song đang tải dữ liệu như thế nào.

Phím tắt nhanh: ⌘N: Thêm URL | ⌘K: Tìm kiếm | ⌘O: Mở thư mục tải | Delete: Xóa lượt tải | Phím cách (Space): Tạm dừng / Tiếp tục
